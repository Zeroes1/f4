# f4 #1218

The second part of the localization and shortcut cleanup makes the two labels
from the Russian keybar actionable and localizable:

- Alt+F3 is a separate `File.ViewHex` action. It opens the selected file in the
  built-in viewer with hex mode forced, bypassing file associations and the
  image/video viewer preference.
- Ctrl+F11 is a `Workspace.Fork` action. It clones the current panels into a
  new workspace through the existing workspace-fork implementation.
- The Russian keybar translates the workspace-fork label as `Копия`; `Hex`
  remains the requested technical label.

Registry, shortcut, action-order, and forced-hex regression tests cover the
changes. Verification is performed by GitHub Actions according to the Lunobot
workflow; local builds and tests are intentionally not run.
