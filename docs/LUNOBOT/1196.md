# f4 #1196

The Windows GUI icon manager now recognizes both native GUI window classes used
by f4: GoGPU and vtui's Win32 host. This makes the embedded f4 icon appear on
the running `f4-gui.exe` window and taskbar for the default Win32 backend as
well as for GoGPU.

A regression test covers the accepted window classes and keeps unrelated
Windows window classes out of the search.

Verification is performed by GitHub Actions according to the Lunobot workflow;
local builds and tests are intentionally not run. The first CI run also checked
the Go formatting and the follow-up commit corrected the alignment reported by
that check.
