# f4 #1258

Закреплены FAR-совместимые мнемоники для основных пунктов меню Files и
Spreadsheet в английском и русском переводах. Для остальных пунктов сохраняется
автоматический подбор свободной буквы, поэтому уникальность меню не нарушается.

Проверка выполняется GitHub Actions согласно правилам Лунобота; локальные сборка
и тесты не запускаются.
