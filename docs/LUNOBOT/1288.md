# f4 #1288

Explicit positional paths are now preserved when the GUI is started without a
terminal, including `f4-gui.exe path1 path2`. A plain GUI start still restores
the saved panel paths.

The regression test covers both behaviours: a terminal-less start with no
paths leaves the environment empty, while explicit paths are resolved against
the command's working directory and passed to the GUI process.

Verification is performed by GitHub Actions according to the Lunobot workflow;
local builds and tests are intentionally not run.
