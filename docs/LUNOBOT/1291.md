# #1291 — Temp Panel: размер содержимого по F3

## Часть 1 из 2

При нажатии F3 на строке `..` в корне Temp Panel теперь запускается
рекурсивный расчёт содержимого всех сохранённых ссылок. Итоговый размер файлов,
а также количество файлов и каталогов, показываются в статусной строке панели.
Расчёт идёт по исходным VFS каждой ссылки, поэтому одинаковые отображаемые
имена не смешивают разные элементы.

Добавлен регрессионный тест для файла и вложенного каталога в Temp Panel.

Вторая часть тикета — исправление выделения и снятия выделения через `+` на
цифровой клавиатуре — остаётся отдельной задачей следующего прохода.

## Проверка

Локальная сборка и тесты по правилам проекта не запускаются. Полная проверка
выполняется GitHub Actions в PR.
