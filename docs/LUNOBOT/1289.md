# #1289 — режим выделения текста мышью

## Что изменено

Глобальный обработчик Shift+левого клика больше не перехватывает клики по
видимой нижней панели F-клавиш. Такой клик сначала обрабатывается `vtui.KeyBar`,
который синтезирует соответствующую F-клавишу с модификатором Shift. Поэтому
Shift+клик по F10 снова вызывает Shift+F10, а Shift+клик вне панели по-прежнему
открывает экранное выделение.

Добавлен регрессионный тест, фиксирующий приоритет обработки клика видимой
панелью F-клавиш.

## Проверка

Локальная сборка и тесты по правилам проекта не запускаются. Полная проверка
выполняется GitHub Actions в PR.
