# Лунобот: покрытие `internal/plughost`

Статус: подготовлены тесты для `extui.go`; локальный Go-запуск не выполнялся по правилам `LUNOBOT.md`.

Основание задачи: Codecov main был 61.5%, пакет `internal/plughost` — 50.55%, а `extui.go` — 6.09% (443 строки). Цель — покрыть безопасные, детерминированные протокольные и валидационные ветви без запуска внешнего UI.

Добавлены проверки:

- framing MessagePack-сообщений и ошибки чтения/записи;
- преобразования числовых типов и границы размеров, координат и Unicode;
- очереди `ExtUiRenderer`, diff/full-кадры, palette, scene, cursor и обработка ошибки отправки;
- преобразование extui-сообщений в события vtinput;
- валидация имени и override-пути внешнего UI, ошибка отсутствующего executable.
